分离逻辑笔记

这是关于分离逻辑 (separation logic) 的笔记.

第1章 引论

分离逻辑相较于Hoare逻辑, 允许局部推理.

分离逻辑的精髓是分离合取/空间合取, 它允许我们在描述规约时避免提及框架, 而在需要时重新引入框架. 框架指的是与当前操作无关的内存区域.

第2章 状态的模型

这里的选择不是唯一的, 而且是ad hoc的.

我们将存储 (store) s定义为从变量到整数的部分函数, 将堆 (heap) h定义为从地址到整数的部分函数. 地址集被定义为自然数集的一个子集. 存储和堆共同构成了状态的模型.

第3章 断言

第3.1节 句法

true 逻辑真 false 逻辑假 p∧q 合取 p∨q 析取 p⇒q 推出 p⁎q 分离合取 p−⁎q 分离推出 e=f 相等 e↦f 指向(堆中) emp 空堆 ∃x.p 存在量化

e和f是整数表达式, x是变量, p和q是断言.

第3.2节 语义

如果存储s和堆h满足断言p, 那么我们记s,h⊨p.

s,h ⊨true 永远为真 s,h ⊨false 永远为假 s,h ⊨ p∧q 如果 s,h ⊨p 且 s,h ⊨q s,h ⊨ p∨q 如果 s,h ⊨p 或 s,h ⊨q s,h ⊨ p⇒q 如果 s,h ⊨p 可以推出 s,h ⊨q s,h ⊨ e=f 如果 [ |e| ] ⁡s = [ |f| ] ⁡s

其中[|e|]⁡s表示e相对于s求值.

剩下的断言的语义均依赖于堆h.

s,h ⊨emp , 如果 h= { } s,h ⊨ e↦f , 如果 h= { [ |e| ] ⁡s → [ |f| ] ⁡s }

这里表达的是堆h恰好就只有一个位置, 而该位置的内容是f的值.

s,h ⊨ p⁎q

分离合取的非形式化语义是: 堆h可以被分为两个部分, p对于其中一个部分成立, 而q对于另外一个部分成立.

s,h ⊨ p⁎q , 如果 ∃ h1 , h2 . ( h1 ⊥ h2 ) ∧ ( h1 ∘ h2 =h ) ∧ ( s, h1 ⊨p ) ∧ ( s, h2 ⊨q )

这里的h1⊥h2代表h1和h2互不相交, 而h1∘h2=h则代表不相交函数复合.

缩略记号: e↦f0,f1,…,fn相当于(e↦f0)⁎(e+1↦f1)⁎⋯⁎(e+n↦fn).

s,h ⊨ p−⁎q

幻灯片上只给出了非形式化的语义, 语焉不详, 容易引起误解, 以下是形式化的版本:

∀ h′ . ( ( h⊥ h′ ) ∧ ( s, h′ ⊨p ) ) ⇒ ( s, ( h∘ h′ ) ⊨q )

换言之, p−⁎q的语义应该理解为如果要了一份资源h′能够让p成立, 那么现有的资源h与新的资源h′合并起来就能让q成立.

第3.3节 ∧和⁎之对比

∧和⁎都是交换的: p∧q当且仅当q∧p, p⁎q当且仅当q⁎p.

当然, 这都是相对于一个任意但固定的模型s,h而言的.

true和emp分别充当了∧和⁎的单位元: p∧true当且仅当p, p⁎emp当且仅当p.

p∧¬p是不可满足的, 但显然p⁎¬p则完全不是一回事了.

第4章 程序的构造

v≔e 变量赋值 v≔ [e] fetch赋值 [e] ≔f 堆变动 v≔ cons⁡ ( e0 ,…, en ) 分配赋值 dispose⁡ (e) 指针弃置

fetch赋值: (相对于某个存储)对于e求值得到一个整数, 这个整数应该是一个地址, 如果堆中没有相应的位置则会报错, 否则的话就取出地址所指向的位置里的内容, 将其赋给该变量.

堆变动: (相对于某个存储)对于e求值得到一个整数, 这个整数应该是一个地址, 如果堆中没有相应的位置则会报错, 否则的话就(相对于某个存储)对于f求值, 将该地址所指向的位置的内容变为f的值.

分配赋值: 找出堆中尚未分配的n个位置, 设其地址分别为l,l+1,…, 对于e0,…,en求值, 然后对于堆进行扩展, 将这些值依次置于这些位置, 最后将l赋给变量v.

指针弃置: 对于e求值得到一个地址, 如果堆中没有相应的位置则会报错, 否则就从堆中去除这个位置.

第5章 公理和推理

第5.1节 Hoare三元组

{p} C {q}

此三元组有效, 如果对于任意的存储s和堆h, 如果s,h⊨p, 那么C在s和h上的执行不会报错, 且经过C修改后的状态s′,h′满足q.

第5.2节 一些公理

{ e↦_ } [e] ≔f { e↦f } { e↦_ } dispose⁡ (e) {emp} {emp} x≔ cons⁡ ( e0 ,…, en ) { x↦ e0 ,…, en } , 其中 e0 ,…, en 不能含有(自由的)x

第5.3节 框架规则

{p} C {q} { p⁎r } C { q⁎r }

附加条件: C所修改的变量不能在r中自由出现.

就个人而言, 观察到以下事实颇为重要: 如果存储s和堆h满足p⁎r, 那么h可以分为h1和h2, 且s,h1⊨p和s,h2⊨r同时成立. 既然{p}C{q}是有效的, 那么C在s和h1上的执行就不能报错. 这虽然看起来是一个平凡的推论, 但是真正重要的是它限定了C产生的副作用只可能影响到h1, 而不可能影响到h2.
