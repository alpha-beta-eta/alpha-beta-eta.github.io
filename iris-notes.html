第2章 later模态

第2.1节 语义

将iris命题P近似地看作序对(k,r)的集合, 其中k是一个自然数而r是一个资源.

将k想成是步数索引, 即多少归约步骤之内我们知道r在P中.

如果(k,r)∈P且m≤k, 那么也有(m,r)∈P.

步骤索引可以解释▷: ▷⁡P = { ( m+1 ,r ) | ( m,r ) ∈P } ∪ { ( 0,r ) | r∈R }

以下我们证明Löb的soundness, 也就是我们要证明(▷⁡P⇒P)⊆P. 当然, 这两边其实是解释. 另外, 我们需要定义 ( P⇒Q ) = { ( k,r ) | ∀ m≤k . ( m,r ) ∈P ⇒ ( m,r ) ∈Q } 令命题P⁡(k)为对于每个资源r, 如果(k,r)∈(▷⁡P⇒P), 那么(k,r)∈P.

P⁡(0)是平凡的, 因为(0,r)∈(▷⁡P⇒P)等价于(0,r)∈P.

假设P⁡(n)成立, 考察P⁡(n+1). 如果(n+1,r)∈(▷⁡P⇒P), 那么(n,r)∈(▷⁡P⇒P). 根据归纳假设, (n,r)∈P. 于是, (n+1,r)∈▷⁡P. 由此可知, (n+1,r)∈P.
