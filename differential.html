第1.1节 关于Banach空间和连续线性映射之概念的回顾

下面的基域𝕂是ℝ或ℂ. 如果E是复向量空间, 那么E具有隐式的实向量空间结构, 限于考虑向量x∈E和标量λ∈ℝ之数乘λ⁢x时.

第1.1.1小节 向量空间E上的范数

范数是满足如下条件的映射ρ:E→ℝ+:

  1. ρ⁡(0)=0; (ρ⁡(x)=0)⇒(x=0);
  2. ρ⁡(x+y)≤ρ⁡(x)+ρ⁡(y),∀x,y∈E;
  3. ρ⁡(λ⁢x)=|λ|⋅ρ⁡(x),∀x∈E,λ∈𝕂.
带有给定范数的向量空间称为赋范向量空间. 当范数ρ给定时, 往往将向量x的范数ρ⁡(x)记为‖x‖. 采用这种记号, 上述条件可以写成:
  1. ‖0‖=0; (‖x‖=0)⇒(x=0);
  2. ‖x+y‖≤‖x‖+‖y‖,∀x,y∈E;
  3. ‖λ⁢x‖=|λ|⋅‖x‖,∀x∈E,λ∈𝕂.

译者注记. i可以合并为(‖x‖=0)⇔(x=0).

设E是一个赋范向量空间, 定义E中两点x,y之距离如下: d⁡ ( x,y ) = ‖ x−y ‖ . 由iii可得‖x−y‖=‖y−x‖, 于是我们有d⁡(x,y)=d⁡(y,x). 又由ii立即可以推出 d⁡ ( x,z ) ≤ d⁡ ( x,y ) + d⁡ ( y,z ) . 最后, d⁡(x,y)=0当且仅当x=y. 因此, E是一个度量空间. 并且和其他度量空间一样, E有拓扑结构. 对于这种拓扑, 范数u↦‖u‖是连续映射E→ℝ, 因为|‖u‖−‖v‖|≤‖u−v‖.

译者注记. u↦‖u‖更是一致连续的.
