第1章 如何(重新)发明Tait的方法

第1.1节 引论

类型论中两个最为重要的发展分别是由W. W. Tait发明的函数类型的Tait方法, 以及之后由J. Y. Girard扩展得到的类型量化的Girard方法, 这两种方法融为一体形成了逻辑关系这个一般性理论, 可用于诸多类型理论. Tait方法继续以其原始名称而为人所知, 即可计算性方法, 其以下面要建立的方式将类型解释为谓词.

Tait所考虑的问题是证明对于简单类型λ演算而言β归约是强规范化的, 这通常定义为不存在自某个良类型项开始的无限β归约序列: M=M0→βM1→β⋯. 一种更好的定义 (具有直接的可用性) 为归约上的超限归纳的有效性, 陈述如下: 对于任意的类型化λ项的性质P, 为了表明P对于所有这样的项都成立, 仅需表明对于每个良类型的类型化项M, 若其所有直接β归约项 (reduct) 满足P则能够推出M也满足P. 更简单地说, 即 ( ∀ M:τ . ( ( ∀ N:τ . M →β N ⊃ P⁡ (N) ) ⊃ P⁡ (M) ) ) ⊃ ∀ M:τ . P⁡ (M) . 强规范化的重要性恰恰就在于由这条原理兑现的证明其他性质的实用性. 例如, 使用归约上的超限归纳, 可以证明弱合流性

第2章 幂集的Tarski不动点定理

第2.1节 引论

Tarski定理说的是完备格上的单调函数具有由不动点构成的完备格, 特别是有最小不动点和最大不动点. {译注: 即其不动点构成了完备格.} 一类实用的特殊情形是由包含关系排序的幂集格.

第2.2节 Tarski定理

令X是一个集合, 不必非空, 并令℘⁡X是由X的所有子集构成的集合. 集合℘⁡X在集合包含关系下构成了一个完备格, 其meet由交给出, join由并给出. 也就是说, 如果X⊆℘⁡X, 那么⋂X是其meet (最大下界), 而⋃X是其join (最小上界). 最小元素是空集的join, 即∅, 而最大元素是空集的meet, 即X.

一个函数F:℘⁡X→℘⁡X是单调的, 如果其保持包含关系: 如果A⊆B⊆X, 那么F⁡(A)⊆F⁡(B)⊆X. 对于℘⁡X上的单调函数F, F的一个前不动点是一个集合A⊆X满足F⁡(A)⊆A, 而F的一个后不动点是一个集合A⊆X满足A⊆F⁡(A). F的前不动点也被称为是F封闭的, F的后不动点也被称为是F一致的. 单调函数F的最小前不动点指的是(在包含关系下)最小的F封闭集合, F的最大后不动点指的是最大的F一致集合. 将这种格视为一个(瘦)范畴的话, 其上的一个单调函数F是一个函子, F的一个前不动点是一个F代数, 而F的一个后不动点是一个F余代数. 因此, F的一个最小前不动点是一个始F代数, F的一个最大后不动点是一个终F余代数.

每个单调函数F:℘⁡X→℘⁡X都有一个(唯一的)最小前不动点和一个(唯一的)最大后不动点, 由以下等式给出: μ⁡ (F) = ⋂ { A⊆X | F⁡ (A) ⊆A } ν⁡ (F) = ⋃ { A⊆X | A⊆ F⁡ (A) } 显然μ⁡(F)被包含于所有F的前不动点之中, 鉴于其是它们之交. {译注: 即μ⁡(F)是每个F的前不动点的子集.} 实际上, μ⁡(F)本身就是F的一个前不动点, 即F⁡(μ⁡(F))⊆μ⁡(F), 因而是最小前不动点. 为了看出这一点, 表明如果F⁡(A)⊆A则有F⁡(μ⁡(F))⊆A. {译注: 这说明F⁡(μ⁡(F))是{A⊆X|F⁡(A)⊆A}的一个下界, 而μ⁡(F)根据定义是其最大下界.} 但是如果F⁡(A)⊆A, 那么根据定义有μ⁡(F)⊆A, 然后根据单调性可得F⁡(μ⁡(F))⊆F⁡(A)⊆A, 而这正是我们所要的. 接着我们又运用单调性可知F⁡(F⁡(μ⁡(F)))⊆F⁡(μ⁡(F)), 这是在说F⁡(μ⁡(F))是F的一个前不动点, 因而μ⁡(F)⊆F⁡(μ⁡(F)). 换言之, μ⁡(F)是F的一个不动点. 并且, 鉴于任何的不动点都是前不动点, μ⁡(F)是最小的不动点. 对偶地, ν⁡(F)包含了所有F的后不动点, 鉴于其是它们之并. 并且, 通过和之前对偶的论证, ν⁡(F)是F的一个后不动点. 因此, 其是最大的后不动点, 又是最大的不动点. (用范畴论的语言来说, 这是Lambek引理, 其是说始F代数和终F余代数都是同构.)

℘⁡X上的单调函数F的最小前不动点兑现了归纳原理: 为了证明μ⁡(F)⊆A, 证明F⁡(A)⊆A就足够了, 这是在说A是F封闭的. 类似地, F的最大后不动点ν⁡(F)兑现了余归纳原理: 为了证明A⊆ν⁡(F), 证明A⊆F⁡(A)就足够了, 这是在说A是F一致的. 以谓词和后承 (implication) 的术语重述, 单调函数F的最小不动点μ⁡(F)是关于X的元素的性质A中满足若x∈F⁡(A)则x∈A的最强性质. 对偶地, 单调函数F的最大不动点是关于X的元素的性质A中满足若x∈A则x∈F⁡(A)的最弱性质. {译注: 这里性质的弱强由满足性质的元素多寡度量, 直觉是如果一个性质被很少的元素满足, 那么我们知道一个元素满足该性质的话, 这就是很多的信息.}

举个例子以说明我所言非虚, 存在两个对于μ⁡(F)⊆ν⁡(F)的证明, 一个用到了μ⁡(F)的最小性, 另一个用到了ν⁡(F)的最大性. 因为μ⁡(F)是F的最小前不动点, 其本身是F封闭的, 而因为ν⁡(F)是F的最大后不动点, 其本身是F一致的. 因此, 为了表明包含关系成立, 要么证明ν⁡(F)是F封闭的, 即F⁡(ν⁡(F))⊆ν⁡(F), 要么证明μ⁡(F)是F一致的, 即μ⁡(F)⊆F⁡(μ⁡(F)), 就足够了. 但是, 这些恰恰是之前为了论证μ⁡(F)和ν⁡(F)是F的不动点而得到的逆向包含关系.

关于单调函数F的最小前不动点和最大后不动点的另一视角由以下对于归纳和余归纳证明的可视化给出. 为了表明μ⁡(F)的每个元素也在表示了我们所关心的性质的集合A之中, 仅需表明μ⁡(F)∩A在F下是封闭的. 因为若的确如此, 则μ⁡(F)被包含于这个交, 因而也就包含于A之中了. 这个交μ⁡(F)∩A先验地就小于(等于)μ⁡(F), 仅仅包含了μ⁡(F)中那些足够好以具有性质A的元素. 但是如果这个交不那么具有限制性到破坏F封闭性的地步, 那么实际上这个交压根就不构成限制, 即μ⁡(F)∩A=μ⁡(F). 对偶地, 为了表明某个元素集合A⊆X包含于ν⁡(F)之中, 仅需大胆断言本就如此, 通过构造ν⁡(F)∪A, 这先验地就大于(等于)ν⁡(F). 但是如果这个并是F一致的, 那么这关于A的断言就不言自明了, 因而ν⁡(F)∪A⊆ν⁡(F). 这个并实际上并没有比ν⁡(F)更大——A的元素一开始就在其中.

我们也能够表明单调函数的任意不动点集合的meet和join仍然是不动点, 但是似乎这不像最小不动点和最大不动点的构造那样有用. 因为我们这里的展开仅仅依赖于交和并的泛性质, 即其相对于集合包含关系是meet和join, 得到对于完备格而言的一般形式Tarski定理是直截了当的, those pre-orders for which all subsets have meets and joins. {译注: 我不太懂数学, 我不知道这里用预序而不是偏序是不是有什么深意, 抑或是仅是单纯的笔误.}

命题(仅为译注补充). 对于完备格X和其上的单调函数F, F的最小不动点和最大不动点均存在.
证明. 令 μ⁡ (F) = ⋀ { x∈X | F⁡ (x) ≤x } ν⁡ (F) = ⋁ { x∈X | x≤ F⁡ (x) } 对于每个x∈X满足F⁡(x)≤x, 我们希望证明F⁡(μ⁡(F))≤x. 鉴于μ⁡(F)本身就是{x∈X|F⁡(x)≤x}的一个下界, 我们有F⁡(μ⁡(F))≤F⁡(x)≤x. 换言之, F⁡(μ⁡(F))也是{x∈X|F⁡(x)≤x}的一个下界, 而μ⁡(F)是最大下界, 故有F⁡(μ⁡(F))≤μ⁡(F), 即μ⁡(F)是F的一个前不动点. 当然, 最小性已由定义给出, 所以μ⁡(F)是F的最小前不动点. 接着, 继续根据单调性, 可知 F⁡ ( F⁡ ( μ⁡ (F) ) ) ≤ F⁡ ( μ⁡ (F) ) 即F⁡(μ⁡(F))也是F的一个前不动点, 所以有 μ⁡ (F) ≤ F⁡ ( μ⁡ (F) ) 根据反对称性, 我们就得到了 F⁡ ( μ⁡ (F) ) = μ⁡ (F) 即μ⁡(F)是F的一个不动点. 并且, 对于每个F的不动点x, x也是F的前不动点 (自反性), 那么μ⁡(F)≤x, 即μ⁡(F)是F的最小不动点. 如法炮制, 可以证明ν⁡(F)是F的最大后不动点, 也是最大不动点.

第2.3节 Bekić引理

有时会出现两个集合 (性质) 是同时归纳定义的, 因为一个定义会依赖于另一个. 这种情况可以通过考虑两个单调算子F,G:℘⁡X×℘⁡X→℘⁡X来表达, 单调意即如果A⊆A′且B⊆B′, 那么F⁡(A,B)⊆F⁡(A′,B)而G⁡(A,B)⊆G⁡(A,B′). 算子(F,G)⁡(A,B)=def(F⁡(A,B),G⁡(A,B))因而相对于逐分量序是单调的, 这个序指的是(A,B)⊆(A′,B′)当且仅当A⊆A′且B⊆B′. 根据和之前给出的论证类似的方法, 其有一个最小不动点μ⁡(F,G), 这是X的子集的一个序对(A0,B0), 满足F⁡(A0,B0)=A0而G⁡(A0,B0)=B0, 每个都要交叉引用另一个, 这是我们所期望的.

第2.4节 断言和规则

不动点构造的一个典型应用是通过一集规则来澄清一个或多个断言, 或者形式判断. 想法在于规则构成了提及的断言的归纳定义. 例如, 以下规则定义了判断 zeronat ZERO nnat succ⁡ (n) nat SUCC 类似地, 偶数和奇数可以由如下规则同时定义: zeroeven ZERO-EVEN neven succ⁡ (n) odd SUCC-ODD nodd succ⁡ (n) even SUCC-EVEN 在这两类情况下, 断言的subject都是Harper (2016) 意义下的抽象绑定树.
