计算类型论

这是Robert Harper写下的一系列关于类型论的讲义, 主要是从更语义的视角看待类型论.

第1章 如何(重新)发明Tait的方法

第1.1节 引论

类型论中两个最为重要的发展分别是由W. W. Tait发明的函数类型的Tait方法, 以及之后由J. Y. Girard扩展得到的类型量化的Girard方法, 这两种方法融为一体形成了逻辑关系这个一般性理论, 可用于诸多类型理论. Tait方法继续以其原始名称而为人所知, 即可计算性方法, 其以下面要建立的方式将类型解释为谓词.

Tait所考虑的问题是证明对于简单类型λ演算而言β归约是强规范化的, 这通常定义为不存在自某个良类型项开始的无限β归约序列: M=M0→βM1→β⋯. 一种更好的定义 (具有直接的可用性) 为归约上的超限归纳的有效性, 陈述如下: 对于任意的类型化λ项的性质P, 为了表明P对于所有这样的项都成立, 仅需表明对于每个良类型的类型化项M, 若其所有直接β归约项 (reduct) 满足P则能够推出M也满足P. 更简单地说, 即 ( ∀ M:τ . ( ( ∀ N:τ . M →β N ⊃ P⁡ (N) ) ⊃ P⁡ (M) ) ) ⊃ ∀ M:τ . P⁡ (M) . 强规范化的重要性恰恰就在于由这条原理兑现的证明其他性质的实用性. 例如, 使用归约上的超限归纳, 可以证明弱合流性

第2章 幂集的Tarski不动点定理

第2.1节 引论

Tarski定理说的是完备格上的单调函数具有由不动点构成的完备格, 特别是有最小不动点和最大不动点. {译注: 即其不动点构成了完备格.} 一类实用的特殊情形是由包含关系排序的幂集格.

第2.2节 Tarski定理

令X是一个集合, 不必非空, 并令℘⁡X是由X的所有子集构成的集合. 集合℘⁡X在集合包含关系下构成了一个完备格, 其meet由交给出, join由并给出. 也就是说, 如果X⊆℘⁡X, 那么⋂X是其meet (最大下界), 而⋃X是其join (最小上界). 最小元素是空集的join, 即∅, 而最大元素是空集的meet, 即X.

一个函数F:℘⁡X→℘⁡X是单调的, 如果其保持包含关系: 如果A⊆B⊆X, 那么F⁡(A)⊆F⁡(B)⊆X. 对于℘⁡X上的单调函数F, F的一个前不动点是一个集合A⊆X满足F⁡(A)⊆A, 而F的一个后不动点是一个集合A⊆X满足A⊆F⁡(A). F的前不动点也被称为是F封闭的, F的后不动点也被称为是F一致的. 单调函数F的最小前不动点指的是(在包含关系下)最小的F封闭集合, F的最大后不动点指的是最大的F一致集合. 将这种格视为一个(瘦)范畴的话, 其上的一个单调函数F是一个函子, F的一个前不动点是一个F代数, 而F的一个后不动点是一个F余代数. 因此, F的一个最小前不动点是一个始F代数, F的一个最大后不动点是一个终F余代数.

每个单调函数F:℘⁡X→℘⁡X都有一个(唯一的)最小前不动点和一个(唯一的)最大后不动点, 由以下等式给出: μ⁡ (F) = ⋂ { A⊆X | F⁡ (A) ⊆A } ν⁡ (F) = ⋃ { A⊆X | A⊆ F⁡ (A) } 显然μ⁡(F)被包含于所有F的前不动点之中, 鉴于其是它们之交. {译注: 即μ⁡(F)是每个F的前不动点的子集.} 实际上, μ⁡(F)本身就是F的一个前不动点, 即F⁡(μ⁡(F))⊆μ⁡(F), 因而是最小前不动点. 为了看出这一点, 表明如果F⁡(A)⊆A则有F⁡(μ⁡(F))⊆A. {译注: 这说明F⁡(μ⁡(F))是{A⊆X|F⁡(A)⊆A}的一个下界, 而μ⁡(F)根据定义是其最大下界.} 但是如果F⁡(A)⊆A, 那么根据定义有μ⁡(F)⊆A, 然后根据单调性可得F⁡(μ⁡(F))⊆F⁡(A)⊆A, 而这正是我们所要的. 接着我们又运用单调性可知F⁡(F⁡(μ⁡(F)))⊆F⁡(μ⁡(F)), 这是在说F⁡(μ⁡(F))是F的一个前不动点, 因而μ⁡(F)⊆F⁡(μ⁡(F)). 换言之, μ⁡(F)是F的一个不动点. 并且, 鉴于任何的不动点都是前不动点, μ⁡(F)是最小的不动点. 对偶地, ν⁡(F)包含了所有F的后不动点, 鉴于其是它们之并. 并且, 通过和之前对偶的论证, ν⁡(F)是F的一个后不动点. 因此, 其是最大的后不动点, 又是最大的不动点. (用范畴论的语言来说, 这是Lambek引理, 其是说始F代数和终F余代数都是同构.)

℘⁡X上的单调函数F的最小不动点兑现了归纳原理: 为了证明μ⁡(F)⊆A, 证明F⁡(A)⊆A就足够了, 这是在说A是F封闭的. 类似地, F的最大不动点ν⁡(F)兑现了余归纳原理: 为了证明A⊆ν⁡(F), 证明A⊆F⁡(A)就足够了, 这是在说A是F一致的. 以谓词和后承 (implication) 的术语重述, 单调函数F的最小不动点μ⁡(F)
