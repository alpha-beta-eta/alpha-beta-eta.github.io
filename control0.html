第6.1节 延续的概念

程序点的延续. 考虑程序执行中的一个点. 这个程序点在该程序中的延续是抵达该点之后还需要执行以完成整个程序执行的计算序列.

往往延续可以作为命令或者函数在编程语言中表示. (见以下例子.) 延续也可以是语义对象, 见以下的第6.3节.

基于语句的语言之中的延续的例子. 考虑以下四个程序, 以具有结构化控制的Algol风格命令式语言写成: p1 = s1 (a) ; s2 p2 = ifbethen s1 (b) else s2 (c) ; s3 p3 = whilebedo s (e) (d) p4 = for i≔1 to10do s (f) 程序点记作(a), (b), 等等. 并且, 要么标记在语句s执行的开始, 如s(a), 要么标记在s执行的结束, 如s(b).

在程序p1中, (a)的延续是语句(b): 一旦执行抵达s1的结束, 序列s1;s2继续以执行s2, 直至抵达程序的结束.

在p2中, (b)的延续是s1;s3, 而(c)的延续是s2;s3. 当条件式的then分支s1已经执行完毕, 我们仍然需要执行s3. 这对于else分支s2也是一样的.

在p3中, (d)的延续是s;whilebedos, 因为我们需要执行循环体s, 然后重新执行while循环直至be为假. 出于相同的原因, (e)的延续是循环whilebedos.

在p4中, (f)的延续是s;whilei≠10do(i≔i+1;s). 我们需要执行计数循环的体s, 然后重新对于递增的i执行该体, 直至i抵达上界10.

子表达式的延续. 在函数式语言之中, 其程序是表达式, 程序点通常标记在对于某个子表达式求值的结束. 因此, 我们可以将程序p的子表达式e的延续想成是函数 e之值 ↦ p之值 这个函数捕获了我们在有了e之值之后为了完成p的求值仍需进行的计算.

基于表达式的语言中的延续的例子. 考虑一个算术表达式的语言, 自左向右求值, 而程序为 p= ( 1+2 ) × ( 3+4 ) p中1的延续是函数λv.(v+2)×(3+4). 从直觉上来说, 在对于1求值得到了一个值v之后, 我们仍需求值加上2和乘上3+4.

p中1+2的延续是函数λv.v×(3+4). 一旦我们已经对于1+2求值完毕, 我们仍不得不计算乘上3+4.

p中3+4的延续是函数λv.3×v, 而非λv.(1+2)×v. 因为求值自左向右进行处理, 我们在开始对于3+4求值之前就已经对于1+2求值过了. 因此, 在我们将3+4求值至v完毕之时, 1+2已经求值为3, 于是所有剩余的工作是计算3×v.

注意到延续依赖于求值策略. 如果我们自右向左求值, 那么p中1+2的延续就会是λv.v×7, 而3+4的延续会是λv.(1+2)×v.

延续和跳跃. 延续的概念可以帮助我们理解跳跃 (goto, break, return, 抛出异常, 等等) 和其他命令 (赋值, 条件式, 等等) 的不同.

考虑一个命令s(b)(a)与其两个程序点, (a)在开始, (b)在结束. 如果s没有包含任何跳跃, 那么(a)的延续总是s后面跟着(b)的延续. 若s是一个跳跃, 那就不是一回事了:

第15.1节 分离逻辑备忘

分离逻辑由Reynolds (2002) 引入, 作为Hoare逻辑的扩展, 其对于使用指针和动态内存分配的程序有着更好的支持. 这样的程序可能会碰到一些难于单独使用平直Hoare逻辑排除的问题 (issue). 例如, 别名 (指向相同块的不同指针变量) 可能会导致藉由某个指针变量的写影响藉由另外指针变量的读. 人们可能会忘了释放一个不再需要的动态分配的块, 这会导致内存泄露. 人们可能会在某个块释放之后访问, 这会导致未定义行为. 除了内存块之外, 诸多类似的资源都会导致类似的问题, 例如系统资源 (文件描述符, 等等), security capabilities, 甚至是某些类型的延续, 这我们会在本章之后看到.

在Hoare逻辑之中, 断言具有真值并描述了程序的可变变量的当前状态. 在分离逻辑之中, 断言既有真值, 也有一个足迹, 这是一集资源, 既描述了这些资源的当前状态, 也描述了其由该断言唯一拥有的事实. 这就使得定义资源敏感 (resource-aware) 逻辑联结词成为可能, 例如分离合取A⁎B, 其成立若A和B断言均成立, 且它们的足迹互不相交. 因此, 如果由A拥有的资源被修改了, B仍然保持有效, 因为B所拥有的资源仍然未被修改.

在资源是动态分配内存块的情形下, 分离逻辑的断言是内存堆上的谓词. 以下是常常使用的断言, 以及它们作为堆h上的谓词的形式化定义. 对于h的domain, 我们记D⁡h, 即h中的有效位置的集合. l↦_ 位置l是有效的 D⁡h = {l} l↦v 位置l含有v D⁡h = {l} ∧ h⁡ (l) =v emp 堆为空 D⁡h =∅ ⟨P⟩ 逻辑命题P成立且堆为空 D⁡h =∅ ∧P A⁎B 分离合取 ∃ h1 , h2 . D⁡ h1 ∩ D⁡ h2 =∅ ∧ h= h1 ∪ h2 ∧ A⁡ ( h1 ) ∧ B⁡ ( h2 ) A−⁎B 分离后承, 或称魔杖 ∀ h′ . D⁡h ∩ D⁡ h′ =∅ ∧ A⁡ ( h′ ) ⇒ B⁡ ( h∪ h′ )

例如, 考虑断言 ∃ n1 , n2 . l1 ↦ n1 ⁎ l2 ↦ n2 ⁎ ⟨ n1 + n2 =10 ⟩ 其陈述了l1和l2是合法的位置, 其分别含有整数n1和n2, 而它们之和为10. 因为该断言使用了分离合取, 所以这也保证了l1≠l2, 即指针l1和l2之间没有别名共享.

因此, 如果我们对于l1的内容进行增量, 我们可以安全地断言 ∃ n1 , n2 . l1 ↦ n1 ⁎ l2 ↦ n2 ⁎ ⟨ n1 + n2 =11 ⟩ 如果没有l1≠l2这一保证, 那么这个结论就是无效的了; 若这两个指针别名共享 (alias), 对于l1的内容进行增量也会对于l2的内容进行增量, 导致和为12.
