第1章 偏序集与格

第1.1节 偏序集

定义1.1.1. 这个定义非常主流, 就不抄写了, 其定义了预序, 预序集, 偏序, 偏序集. 和主流不同的是, 其要求预序集和偏序集非空, 之后的论述的确也默认非空性, 必须小心.
例子1.1.1.
  1. 实数集ℝ, 有理数集ℚ, 整数集ℤ, 自然数集ℕ, 非负整数集ℕ⁎在通常的小于等于关系下构成偏序集, 其实就是通常的序关系下的意思. 这本书的一个背离当前主流记号的地方是ℕ是不包含零的, 而ℕ⁎是加了零的.
  2. 如果使用|表示整除, 即m|n表示m整除n, 那么(ℕ,|)是一个偏序集.
  3. 定义ℝ上的一个二元关系⪯如下: x⪯y ⟺ ⌊x⌋ ≤ ⌊y⌋ 则(ℝ,⪯)是一个预序集, 但不是偏序集.
  4. 对于集合X, 其幂集𝒫⁡(X)在关系⊆下是一个偏序集. 当然了, 这个幂集的非空子集继承了自然的序关系也成为偏序集. 原书要求X非空是不必要的, 因为𝒫⁡(X)即便在X是空集的情况下也非空.
  5. 设G是一个群, Sub⁡(G)是由其所有子群构成的集合. 那么, (Sub⁡(G),⊆)是一个偏序集.
  6. 设Σ⁎是由所有0,1字符的有限序列构成的集合, 定义a≤b当且仅当a是b的前缀, 则(Σ⁎,≤)是一个偏序集.
  7. 设P是一个偏序集 (当然已经默认非空了), X是一个集合, 定义PX上的关系≤为 f≤g ⟺ ∀ x∈X . f⁡ (x) ≤ g⁡ (x) 那么≤是一个偏序关系, 其被称为PX上的逐点序 (pointwise order). 原文需要X非空, 实则不需要.
  8. 设I⁡(ℝ)={[a,b]|a≤b,a,b∈ℝ}, 定义 [ a1 , b1 ] ⊑ [ a2 , b2 ] ⟺ [ a2 , b2 ] ⊆ [ a1 , b1 ] 则(I⁡(ℝ),⊑)是一个偏序集, 而⊑是ℝ上的区间序或者信息序. 信息序这个名字应该来源于指称语义学, 区间越小越精细, 信息越多.
  9. 设(X,O⁡(X))是一个拓扑空间, 定义 ≤ O⁡ (X) = { ( x,y ) ∈ X×X | x∈ {y} − } 那么≤O⁡(X)是一个预序, 称为X的特殊化序 (specialization order). 记Θ⁡(X,O⁡(X))=(X,≤O⁡(X)). 容易证明, ≤O⁡(X)是一个偏序当且仅当X是T0空间. 之所以称为特殊化, 或许是特殊化序还要另外一种刻画方式, 即x≤y当且仅当包含x的开集族是包含y的开集族的子集. 一个点所处于的开集越多, 也就越特殊.

设(P,≤)是一个偏序集, Q是P的一个非空子集. 记 ≤Q = { ( x,y ) ∈ Q×Q | x≤y } 则≤Q是Q上的一个偏序, 称为Q在P中的继承序或者导出序或者诱导序或者限制序, 而(Q,≤Q)是(P,≤)的一个子偏序集. 对于n∈ℕ, 记n={0,1,2,…,n−1}为ℕ⁎的子偏序集.

定义1.1.2. 设P是一个偏序集, A⊆P.
  1. 如果对于任意的x∈A和y∈P, x≤y可以推出y∈A, 那么称A为上集 (upper set).
  2. 如果对于任意的x∈A和y∈P, y≤x可以推出y∈A, 那么称A为下集 (lower set).
分别记P的所有下集和上集构成的集合为D⁡(P)和U⁡(P), 它们都是P上的Alexandrov拓扑.

定义1.1.3. 设P是一个偏序集, 对于x,y∈P, 如果x<y, 且对于每个z∈P, x≤z≤y可以推出z=x或z=y, 那么称y覆盖 (cover) x, 记作x≺y.

一般来说, 偏序集可以用Hasse图来描述. Hasse图存在几个方面, 或者说几种不同的含义. 一种可能是Hasse图是纯粹技术意义上的graph, 还有一种可能是Hasse图是一种图示. 不过, 我感觉还是图示意义下的Hasse图更频繁出现. 我们将具有覆盖关系的元素用线段连接, 一般较小元素安排在下方, 较大元素安排在上方, 无法比较的平行元素则一般尽可能安排在同一高度.

设P是一个偏序集, a∈P. 如果对于每个x∈P有a≤x, 那么称a是P的最小元或者底 (bottom), 记作0P或者0. 类似地可以定义P的最大元并记作1P或者1. 具有最小元和最大元的偏序集称为有界的 (bounded). 如果对于每个x∈P都有x≤a可以推出x=a, 那么就称a为P的极小元. 换言之, 没有其他元素比a更小了. 类似地可以定义极大元. 显然, 最小元是一个极小元, 最大元是一个极大元. 设S是P的一个子偏序集, S的极小元集合记作min⁡(S), 而极大元集合记作max⁡(S). 它们当然都有可能是空集. 另外, 最小元记作Min⁡(S), 最大元记作Max⁡(S). 最小元和最大元并不一定存在, 但是若存在则显然唯一 (对于偏序集而言).

第2章 Galois伴随和Galois连接

本章标题中的两个名字在许多文献中存在着大量混用的现象, 现在我们从历史发展的角度阐述它们的异同点. 特别指出, Galois伴随的英文是Galois correspondence或Galois adjunction, 而Galois连接 (也称Galois联络) 英文则是Galois connection, 两者都是两个偏序集之间满足一定条件的映射序对.

第2.1节 Galois伴随

虽然Galois连接出现得比Galois伴随更早, 然而从格论的角度来看, Galois伴随给人以更加自然和实用之感. 因此, 我们先在本节介绍Galois伴随及其相关结果.

定义2.1.1. 如图2.1所示, 设f:P→Q和g:Q→P是偏序集之间的保序映射, 如果对于任意的a∈P和b∈Q都有 f⁡ (a) ≤b ⟺ a≤ g⁡ (b) 则称(f,g)是从P到Q的一个Galois伴随, 记作 f⊣g : P⇀Q 如果P=Q, 则称(f,g)是P上的一个Galois伴随.

这里的f和g有位置之分: f位于不等号的左侧, 而g位于右侧. 一般情况下, 称f是g的左伴随, g是f的右伴随. 有些文献也将f,g分别称为上伴随和下伴随.

例子2.1.1.
  1. 设R⊆X×Y是一个二元关系, 分别定义R→:𝒫⁡(X)→𝒫⁡(Y)和R←:𝒫⁡(Y)→𝒫⁡(X)为 R→ ⁡ (A) = { y∈Y | ∃ x∈A . ( x,y ) ∈R } R← ⁡ (B) = { x∈X | ( x,y ) ∈R ⇒ y∈B } 则R→⊣R←:𝒫⁡(X)⇀𝒫⁡(Y).
  2. 设R⊆X×Y是一个二元关系, 分别定义R→:𝒫⁡(X)→𝒫⁡(Y)和R←:𝒫⁡(Y)→𝒫⁡(X)为 R → ⁡ (A) = { y∈Y | ( x,y ) ∈R ⇒ x∈A } R ← ⁡ (B) = { x∈X | ∃ y∈B . ( x,y ) ∈R } 则R←⊣R→:𝒫⁡(Y)⇀𝒫⁡(X).
  3. 设f:X→Y是一个映射. 将f视为二元关系{(x,f⁡(x))|x∈X}, 由1知f→⊣f←:𝒫⁡(X)⇀𝒫⁡(Y)其中 f→ ⁡ (A) = { f⁡ (x) | x∈A } f← ⁡ (B) = { x∈X | f⁡ (x) ∈B }

Galois伴随除了用当且仅当的方式定义之外, 还可以利用映射的复合与偏序关系进行刻画.

定理2.1.1. 设f:P→Q和g:Q→P是偏序集之间的保序映射, 则下列条件等价:
  1. f⊣g:P⇀Q;
  2. idP≤g⁢f,f⁢g≤idQ.
证明. 1推出2: 对于任意的x∈P, 由f⁡(x)≤f⁡(x)可以推出x≤(g⁢f)⁡(x), 即idP≤g⁢f. 对于任意的y∈Q, 由g⁡(y)≤g⁡(y)可以推出(f⁢g)⁡(y)≤y, 即f⁢g≤idQ.
2推出1: 对于任意的x∈P和y∈Q, 如果f⁡(x)≤y, 根据单调性可知(g⁢f)⁡(x)≤g⁡(y), 又因为idP⁡(x)≤(g⁢f)⁡(x), 于是idP⁡(x)≤g⁡(y), 即x≤g⁡(y). 如果x≤g⁡(y), 那么根据单调性可知f⁡(x)≤(f⁢g)⁡(y), 又因为(f⁢g)⁡(y)≤idQ⁡(y), 于是f⁡(x)≤idQ⁡(y), 即f⁡(x)≤y.

定理2.1.2. 设f⊣g:P⇀Q, 则
  1. f⁢g⁢f=f, g⁢f⁢g=g;
  2. g⁢f:P→P是闭包算子, f⁢g:Q→Q是内部算子.
证明.
  1. 我们知道idP≤g⁢f, 于是对于每个x∈P都有x≤(g⁢f)⁡(x). 根据单调性, 可知f⁡(x)≤(f⁢g⁢f)⁡(x). 另外, 根据f⁢g≤idQ, 我们知道对于每个x∈P都有(f⁢g)⁡(f⁡(x))≤idQ⁡(f⁡(x)), 即(f⁢g⁢f)⁡(x)≤f⁡(x). 因此, f⁢g⁢f=f. 我们知道f⁢g≤idQ, 于是对于每个y∈Q都有(f⁢g)⁡(y)≤y. 根据单调性, 可知(g⁢f⁢g)⁡(y)≤g⁡(y). 另外, 根据idP≤g⁢f, 我们知道对于每个y∈Q都有idP⁡(g⁡(y))≤(g⁢f)⁡(g⁡(y)), 即g⁡(y)≤(g⁢f⁢g)⁡(y). 因此, g⁢f⁢g=g.

虽然Galois伴随的两个偏序集不一定序同构, 但是我们可以通过缩小定义域和陪域的方式得到一组序同构的偏序集.

定理2.1.3. 如果f⊣g:P⇀Q, 则f⁡(P)≅g⁡(Q).
证明. 将f限制为φ:g⁡(Q)→f⁡(P), 将g限制为ψ:f⁡(P)→g⁡(Q). 对于每个x∈g⁡(Q), 存在y∈Q满足x=g⁡(y), 于是 ( ψ⁢φ ) ⁡ (x) = ( g⁢f ) ⁡ (x) = ( g⁢f ) ⁡ ( g⁡ (y) ) = ( g⁢f⁢g ) ⁡ (y) = g⁡ (y) = x 同理, 我们可以推出 ( φ⁢ψ ) ⁡ (y) =y 对于每个y∈f⁡(P)成立. 也就是说, φ和ψ是可逆的保序映射, 也就是序同构.

定理2.1.4. 设f:P→Q和g:Q→P是偏序集之间的保序映射, 那么下列条件等价:
  1. f⊣g:P⇀Q;
  2. ∀a∈P.f⁡(a)=Min⁡(g−1⁡(↑⁡a));
  3. ∀b∈Q.g⁡(b)=Max⁡(f−1⁡(↓⁡b)).
证明. 1推出2: 对于任意的a∈P, 由于a≤g⁡(f⁡(a)), 我们有f⁡(a)∈g−1⁡(↑⁡a); 任取y∈g−1⁡(↑⁡a), 我们有a≤g⁡(y), 从而f⁡(a)≤y. 这说明f⁡(a)=Min⁡(g−1⁡(↑⁡a)).

第3章 Heyting代数

Heyting代数由荷兰数学家A. Heyting于1930年引入. 由于其逻辑排中律一般不再成立, 所以Heyting代数可以看作直觉主义逻辑演算的Tarski-Lindenbaum代数. 在数学方面, Heyting代数是Boole代数的一般化, 曾被称为伪Boole代数或Brouwer格.

第3.1节 Heyting代数的基本概念

定义3.1.1. 设H是一个格, 若存在二元运算→:H×H→H使得 ∀ a,b,c ∈H . c∧a ≤b ⟺ c≤ a→b 则称H为Heyting代数.

容易验证, H有最大元但不一定有最小元. 有些文献会假定Heyting代数是一个有界格.

由Heyting代数的定义和第2章中Galois伴随之性质, 我们有以下定理.

定理3.1.1. 设H是一个格, 则下列条件等价:
  1. H为Heyting代数;
  2. 对于任意的a∈H, (a∧(-),a→(-))构成H上的Galois伴随;
  3. 对于任意的a,b∈H, {x∈H|a∧x≤b}存在最大元.
证明. 1推出2: 根据Galois伴随的定义, 我们需要证明对于任意的x,y∈H, 都有 a∧x ≤y ⟺ x≤ a→y 而这由Heyting代数的定义所保证. 我们还需要说明这两个函数的单调性. 如果x≤y, 那么a∧x≤a∧y, 这可由定义得到. 如果x≤y, 我们要证明a→x≤a→y. 根据a→x≤a→x, 根据剩余律我们有(a→x)∧a≤x, 鉴于x≤y, 所以有(a→x)∧a≤y, 再用一次剩余律可知a→x≤a→y.
2推出1: 根据1推出2的证明, 这就是立即可以得到的.
1推出3: 我们欲说明a→b是{x∈H|a∧x≤b}的最大元. 首先, 根据1推出2的证明过程, 我们知道a∧(a→b)≤b这一事实, 于是(a→b)∈{x∈H|a∧x≤b}. 其次, 如果c∈H满足a∧c≤b, 那么根据剩余律c≤a→b. 由此, 我们知道b→c就是最大元.
3推出1: 我们定义(a→b)≔Max⁡({x∈H|a∧x≤b}), 当然这是良定的. 接着, 我们需要证明剩余律. 对于任意的a,b,c∈H, 如果c∧a≤b, 即c∈{x∈H|a∧x≤b}, c≤a→b根据定义即得. 如果c≤a→b, 那么c∧a≤(a→b)∧a≤b, 这就是根据a→b的定义得到的.
