第1.5节 理想和滤子

设P是一个偏序集, S⊆P. 如果S非空, 且对于任意的x,y∈S都存在z∈S使得x,y≤z, 则称S是P的有向子集/定向子集 (directed subset); 如果S非空且对于任意的x,y∈S都存在z∈S使得z≤x,y, 则称S是P的滤过子集/可滤子集 (filtered subset).

定义1.5.1. 设P是一个偏序集, I,F⊆P.
  1. 如果I是一个定向下集, 则称I是P的理想 (ideal);
  2. 如果F是一个滤过上集, 则称F是P的滤子 (filter).

如果S是P的一个理想 (respectively, 滤子), 且S≠P, 那么称S是P的真理想 (proper ideal) (respectively, 真滤子). 对于任意的x∈P, 子集↓x (respectively, ↑x) 是一个理想 (respectively, 滤子), 其被称为关于x的主理想 (principal ideal) (respectively, 主滤子 (principal filter)). 我们记Idl⁡(P)为P的所有理想构成的集合, Fil⁡(P)为P的所有滤子构成的集合. 注意, 理想和滤子首先都是非空子集.

例子1.5.1.
  1. 对于任意的a∈ℝ, (−∞,a]和(−∞,a)都是ℝ的理想, [a,+∞)和(a,+∞)都是ℝ的滤子.
  2. 设X是一个非空集合, Fin⁡(X)={A⊆X|A有限}是𝒫⁡(X)的理想, CoFin⁡(X)={A⊆X|A′有限}是𝒫⁡(X)的滤子.
  3. 设(X,O⁡(X))是一个拓扑空间, 对于任意的x∈X, N⁡(x)是(𝒫⁡(X),⊆)的滤子, U⁡(x)是(O⁡(X),⊆)的滤子, 其中 N⁡ (x) = { V⊆X | ∃ U∈ O⁡ (X) , x∈ U⊆V } 而 U⁡ (x) = { U∈ O⁡ (X) | x∈U }
定理1.5.1. 设L是一个格, I是L的非空子集, 则下列条件等价:
  1. I是理想;
  2. I是对于∨封闭的下集;
  3. I对于∨封闭, 对于∧吸收 (即对于a∈I和b∈L, 都有a∧b∈I).
证明. 由1推出2: 对于x,y∈I, 我们知道存在z∈I满足x,y≤z. 换言之, z是x和y的一个上界, 那么x∨y≤z. 鉴于I是一个理想 (故为下集), 那么x∨y∈I, 即I对于∨封闭.
由2推出3: 对于a∈I和b∈L, 我们知道a∧b≤a. 鉴于I是一个下集, 所以a∧b∈I, 也就是I对于∧吸收.
由3推出1: 由于I对于∨封闭, 故I是一个定向子集. 如果y∈I而x≤y, 那么根据吸收性质, 有x∧y∈I, 由因为x≤y等价于x∧y=x, 所以说x∈I, 也就是说I是一个下集.

练习1. 找出所有的4元偏序集和5元格.
解答.
练习2. 设(P,≤P)和(Q,≤Q)是两个偏序集, 在笛卡尔积P×Q上定义二元关系如下: ( x1 , y1 ) ≤ ( x2 , y2 ) ⟺ x1 <P x2 或 x1 = x2 , y1 ≤Q y2 . 证明: ≤是P×Q上的一个偏序, 其被称为P×Q上的字典序 (lexicographic order), 且≤是全序当且仅当≤P和≤Q都是全序.
证明. 对于每个(x,y)∈P×Q, 我们有x=x和y≤Qy, 故(x,y)≤(x,y), 这就说明了自反性. 对于任意的(x1,y1)≤(x2,y2)和(x2,y2)≤(x3,y3), 鉴于≤的两个条件是互斥的, 所以说其实就是四种情况.
◻
练习3. 设P是一个偏序集, f,g:P→P是闭包算子, 证明下列条件等价:
  1. f≤g;
  2. f∘g=g;
  3. g∘f=g;
  4. Im⁡(g)⊆Im⁡(f).
证明.
  1. 由1推出2: 根据f的增值性, g⁡(x)≤f⁡(g⁡(x)). 根据f≤g, f⁡(g⁡(x))≤g⁡(g⁡(x)). 又根据g的幂等性, f⁡(g⁡(x))≤g⁡(x). 综上所述, f⁡(g⁡(x))=g⁡(x). 鉴于x的任意性, 故f∘g=g.
  2. 由2推出3: 根据f的增值性, x≤f⁡(x). 根据g的单调性, g⁡(x)≤g⁡(f⁡(x)). 根据f∘g=g和g的幂等性, 可以推出g⁡(f⁡(g⁡(x)))=g⁡(g⁡(x))=g⁡(x). 根据g的增值性, x≤g⁡(x). 根据g和f的单调性, g⁡(f⁡(x))≤g⁡(f⁡(g⁡(x))), 即g⁡(f⁡(x))≤g⁡(x). 综上所述, g⁡(f⁡(x))=g⁡(x). 鉴于x的任意性, 故g∘f=g.
  3. 由3推出1: 根据g的增值性, f⁡(x)≤g⁡(f⁡(x)). 又根据g∘f=g, 可以得到f⁡(x)≤g⁡(x). 鉴于x的任意性, 有f≤g.
根据以上推理, 可知1, 2, 3是等价的.
  1. 由2推出4: 根据f∘g=g, 可知Im⁡(f∘g)=Im⁡(g). 又因为Im⁡(f∘g)⊆Im⁡(f), 故Im⁡(g)⊆Im⁡(f).
  2. 由4推出2: 因为Im⁡(g)⊆Im⁡(f), 所以g⁡(x)∈Im⁡(f). 于是, 存在y∈P使得g⁡(x)=f⁡(y). 那么, 根据f的幂等性, 可以推出f⁡(g⁡(x))=f⁡(f⁡(y))=f⁡(y)=g⁡(x). 鉴于x的任意性, 可知f∘g=g.
◻

第2.1节 Galois伴随

定义2.1.1. 设f:P→Q和g:Q→P是偏序集之间的两个保序映射, 如果对于任意的a∈P,b∈Q都有 f⁡ (a) ≤b ⟺ a≤ g⁡ (b) 那么则称序对(f,g)是从P到Q的一个Galois伴随 (Galois correspondence或Galois adjunction), 记作 f⊣g : P⇀Q . 如果P=Q, 则称(f,g)是P上的一个Galois伴随.
